# UNMUTED winter photos

HD copies of the winter hoodie photos for the UNMUTED store theme («UNMUTED على رائد» on Salla), served by jsDelivr.
`photos/<hoodie>/<pose>.webp` is 3200×4000, `md/` 1600×2000 and `sm/` 800×1000, on the page colour #FAF5EF.
The theme (unmutedsa/unmuted-raed, unmuted-raed.js) swaps Salla's 720×900 copies for these.
